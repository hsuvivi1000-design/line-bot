# Architecture Designer

當使用者呼叫 `/architecture` 時，請根據 PRD 進行系統的架構設計。

## 執行步驟
1. 取出並閱讀已生成的 `docs/PRD.md`，理解系統核心功能與需求。
2. 規劃合適的系統架構，包含：
   - 技術選型 (Frontend, Backend, Database)
   - 系統組件與資料流向描述
   - 目錄結構規劃 (Directory Structure)
3. 採用 Markdown 格式輸出架構設計文件。
4. 預設將文件儲存於 `docs/ARCHITECTURE.md` 中。
